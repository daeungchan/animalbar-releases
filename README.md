# animalbar

**데스크탑에서 함께 사는 픽셀 동물 목장** — macOS 데스크탑 펫 / 방치형 수집 게임

동물들이 화면 하단(독 위)을 돌아다니는 투명 오버레이 게임입니다. 여러분이 평소처럼 **타이핑하고 클릭할 때마다 재화가 떨어지고**, 동물들이 주워 모읍니다. 모은 재화로 알을 부화시키고, 동물을 수집·합성하고, 배경을 해금하세요.

## 주요 특징

- ⌨️ **작업하면서 플레이** — 키보드·마우스 입력이 곧 게임 자원. 따로 조작할 필요 없음
- 🐾 **동물 48종 수집** — 5단계 등급 합성, 도감, 스킬 7종
- 🗺️ **배경 6종 해금** — 숲·바닷속·목장·정글·판타지·지옥, 배경마다 전용 재화 스킨과 어울리는 동물 보너스
- 🧭 **탐험** — 동물을 원정 보내 보상 획득, 전설의 용·불사조는 탐험에서만
- 🔥 **콤보 & 피버** — 입력 콤보 500 스택마다 클럽 피버 쇼

## 설치 (macOS)

1. [Releases](../../releases)에서 최신 `animalbar-vX.X.X-macos.zip`을 내려받아 압축 해제
2. 처음 열 때는 `animalbar.app` **우클릭 → 열기** ("확인되지 않은 개발자" 경고가 뜨면: 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기")
3. 실행 후 **입력 모니터링 권한** 허용 — 타이핑·클릭으로 재화가 떨어지는 게임 특성상 필요합니다
4. 우측 하단 좌판에서 알을 구매해 첫 동물을 만나보세요

## 시스템 요구사항

- macOS (Apple Silicon)
- Windows 빌드는 검증 후 추가 예정
